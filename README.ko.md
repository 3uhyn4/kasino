<h1 align="center">Kasino</h1>

<p align="center">맥 메뉴바와 윈도우 트레이에서 쓰는 카지노 연습 앱<br>
<a href="README.md">English</a> · 한국어</p>

연습용 뱅크롤로 바카라, 용호, 룰렛, 홀덤, 슬롯을 해 볼 수 있습니다. 승률이 어떤지, 결과 중 어디까지가 운이었는지, 홀덤에서 판단을 제대로 했는지까지 기록해 줍니다.

연습용이라 실제 돈은 오가지 않습니다. 결제나 환전 기능도 없습니다.

## 들어 있는 것

- 바카라: 페어, 드래곤 보너스 사이드 베팅. 그림장(본매, 대로, 대안로, 소로, 바퀴벌레) 전부 지원
- 용호: 그림장 포함
- 룰렛: 유럽식. 원하는 숫자나 구역을 여러 개 찍고 한 번에 돌리면 됩니다. 최근 100판 기록과 빨강·검정, 홀·짝, 구간별 비율, 많이 나온 번호와 오래 안 나온 번호를 보여줍니다
- 홀덤: AI 3명과 치는 리밋 홀덤. 코치를 켜면 내 차례에 승률과 팟 오즈, 추천 액션을 보여주고, 끝나고 나서 그 판단이 맞았는지 알려줍니다
- 랭크 모드: 아이디와 비밀번호로 가입하면 1,000칩을 받습니다. 모든 게임을 이 칩으로 하고, 가진 칩이 많은 순서로 전체 순위가 매겨집니다. 연습 모드 뱅크롤과는 따로입니다
- 슬롯
- 통계: 게임별 승률과 손익, 뱅크롤 그래프, 운 지수(실제 손익에서 하우스 엣지 기준 기대 손익을 뺀 값)
- 한국어, 영어, 일본어 / 라이트, 다크 모드

## 다운로드

[Releases](../../releases/latest)에서 최신 버전을 받으면 됩니다.

**맥** (macOS 13 이상): `Kasino-x.y.z.dmg`를 열고 Kasino를 응용 프로그램 폴더로 끌어다 놓으세요. 애플 공증을 받지 않은 앱이라, 처음 열기 전에 터미널에 아래 한 줄을 한 번 붙여넣어야 합니다.

```
xattr -dr com.apple.quarantine /Applications/Kasino.app
```

같은 안내가 DMG 안에도 들어 있습니다. 그다음부터는 메뉴바에 떠 있습니다.

**윈도우** (10, 11): 설치하려면 `Kasino-Setup-x.y.z.exe`, 설치 없이 쓰려면 `Kasino-x.y.z-portable.exe`를 실행하세요. "Windows의 PC 보호" 창이 뜨면 추가 정보 > 실행을 누르면 됩니다. 시계 옆 트레이에 들어가 있고, 클릭하면 열리고 우클릭하면 종료할 수 있습니다.

## 직접 빌드하기

맥: `mac/build.sh`를 실행하면 `mac/build`에 앱과 DMG가 생깁니다. Xcode 명령줄 도구가 필요합니다.

윈도우: `cd windows`, `npm install`, `npm run dist` 순서로 실행하면 `windows/dist`에 설치 파일이 생깁니다. 실행만 해 보려면 `npm start`.

`v1.0.1` 같은 태그를 올리면 GitHub Actions가 두 버전을 빌드해서 새 릴리스에 붙여 줍니다.

## 개인정보

로그인은 선택입니다. 계정이 없으면 아무것도 컴퓨터 밖으로 나가지 않습니다.

계정을 만들면 순위표에 표시하기 위해 아이디, 닉네임, 칩 잔액, 암호화된 비밀번호(비밀번호 원문은 저장하지 않음)를 서울에 있는 Supabase 서버에 저장합니다. 이메일 등 다른 개인정보는 받지 않습니다. 설정 > 계정에서 언제든 계정과 순위표 기록을 삭제할 수 있습니다.
